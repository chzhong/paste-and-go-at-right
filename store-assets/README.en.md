# Chrome Web Store assets

[简体中文](README.md) · English

- `promo-small.png`: 440×280 small promotional tile.
- `promo-small.svg`: editable source for the promotional tile; do not upload it to the store.
- `screenshots/`: add real Chrome usage screenshots here. See `docs/publishing/chrome-web-store.en.md` for requirements.

The store requires at least one real screenshot. Do not present a promotional graphic or synthetic interface as an actual product screenshot.
