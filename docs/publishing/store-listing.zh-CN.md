# Chrome Web Store 商店文案（简体中文）

简体中文 · [English](store-listing.en.md)

## 名称

Paste and Go at Right

## 简短说明

从标签页右键菜单，在右侧标签页或拆分视图中打开剪贴板里的网址。全部处理均在本机完成。

## 详细说明

Paste and Go at Right 为经常复制网址的用户减少重复操作。

复制一个完整的 HTTP 或 HTTPS 地址，然后右键点击任意标签页：

- 在被点击标签页右侧新建标签页并打开网址；
- 点击插件图标进入设置页，查看两项快捷键并前往 Chrome 分别分配按键；
- Chrome 155 及以上版本可直接在原生拆分视图中打开网址；
- 剪贴板不是网址时，不显示相关菜单。

隐私优先：剪贴板只在设备本地临时读取和校验，不会上传、保存或分享。本扩展没有账号、遥测、广告或分析服务。

## 分类建议

生产力工具（Productivity）

## 单一用途说明

从 Chrome 标签页右键菜单打开剪贴板中的 HTTP/HTTPS 网址。

## 权限理由

### clipboardRead

在设备本地读取纯文本剪贴板，判断其是否为 HTTP/HTTPS 网址，以决定是否显示菜单；用户点击菜单时再次读取要打开的网址。内容不会保存或传输。

### contextMenus

在 Chrome 标签页右键菜单中提供“在右侧新增标签页并打开”和支持时的“在拆分视图粘贴并打开”。

### offscreen

Manifest V3 Service Worker 无法直接访问 DOM 剪贴板能力，因此需要本地 offscreen 文档读取剪贴板。该文档不加载远程内容。

## 数据披露建议

扩展会在本地处理用户剪贴板文本，即使不上传也应在 Privacy practices 中如实披露。根据控制台当时提供的分类，至少披露与剪贴板文本相符的“网站内容/用户提供的内容”，并声明：

- 仅为扩展单一功能处理；
- 不出售，不用于广告或信用评估；
- 不传输给第三方；
- 不持久保存；
- 遵守 Limited Use 要求。

最终选择应以提交时 Developer Dashboard 的实际字段和扩展真实行为为准。

## 测试说明

1. 复制 `https://example.com/`。
2. 等待最多一秒，然后右键点击 Chrome 标签栏中的任意标签页。
3. 验证出现打开菜单，并可在右侧标签页打开该网址。
4. 在 Chrome 155+ 验证拆分视图菜单。
5. 打开插件设置页，在 `chrome://extensions/shortcuts` 分别分配两个快捷键；验证右侧打开操作，并在 Chrome 155+ 验证拆分视图操作。
6. 复制普通文本并等待最多一秒，验证菜单消失。

无需账号或测试凭据。
