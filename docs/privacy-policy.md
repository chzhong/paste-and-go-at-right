# Paste and Go at Right 隐私政策

最后更新：2026 年 10 月 12 日

Paste and Go at Right（以下简称“本扩展”）的单一用途，是让用户从 Chrome 标签页右键菜单快速打开剪贴板中的网址。

## 处理的数据

本扩展会在用户设备本地读取纯文本剪贴板内容，用于判断其是否为完整的 HTTP/HTTPS URL。用户点击菜单时，本扩展会再次读取并校验该内容，然后要求 Chrome 打开该网址。

剪贴板可能包含用户数据。本扩展仅为上述用户可见功能临时处理当前纯文本内容。

## 数据存储、传输和共享

- 本扩展不会把剪贴板内容保存到本地存储、文件、日志或数据库。
- 本扩展不会把剪贴板内容或使用数据发送给开发者、广告商、分析服务或任何第三方。
- 本扩展不包含账号系统、遥测、分析、广告或远程代码。
- 本扩展不会出售用户数据，也不会允许人工读取用户数据。

当用户选择打开网址时，Chrome 会像正常浏览行为一样访问该网址；目标网站的数据处理受其自身隐私政策约束。

## 权限用途

- `clipboardRead`：在本机读取纯文本剪贴板，以判断是否显示菜单，并在点击时获得要打开的网址。
- `contextMenus`：在标签页右键菜单中提供打开操作。
- `offscreen`：Manifest V3 Service Worker 没有 DOM，扩展使用隐藏的本地文档访问剪贴板能力。

## 数据保留和删除

本扩展不持久保存用户数据，因此没有服务器端或本地数据需要用户请求删除。卸载扩展会移除扩展自身的代码与设置。

## Chrome Web Store Limited Use

本扩展对用户数据的使用符合 Chrome Web Store User Data Policy（包括 Limited Use 要求）：数据仅用于提供清楚披露的单一功能，不用于广告、画像、信用评估、转售或其他无关用途。

## 政策变更

如果数据处理方式发生变化，本政策和 Chrome Web Store 披露会在新版本发布前同步更新。
