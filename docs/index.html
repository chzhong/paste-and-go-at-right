Three steps.
No detour. 三步完成，
没有绕路。

The extension stays out of the way until your clipboard contains a complete HTTP or HTTPS URL. 只有当剪贴板包含完整的 HTTP 或 HTTPS 网址时，扩展菜单才会出现。

1

Copy a URL复制网址

Copy one complete HTTP or HTTPS address from any app.从任意应用复制一个完整的 HTTP 或 HTTPS 地址。

2

Right-click a tab右键点击标签页

The action appears in Chrome's native tab context menu only when it is useful.仅在剪贴板是网址时，操作才会出现在 Chrome 原生标签页菜单中。

3

Choose the layout选择打开方式

Open a tab immediately to the right, or use native Split View on Chrome 155+.在右侧打开新标签页，或在 Chrome 155+ 中使用原生拆分视图。

Privacy by design隐私优先设计

Your clipboard stays yours.剪贴板始终属于你。

Clipboard text is checked temporarily on your device. Nothing is uploaded, stored, logged, sold, or shared.剪贴板文本只在设备本地临时检查，不上传、不保存、不记录、不出售，也不分享。

Read the privacy policy阅读隐私政策
  • No accounts or sign-in无需账号或登录
  • No telemetry or analytics没有遥测或分析服务
  • No advertising or tracking没有广告或追踪
  • No remote code or backend没有远程代码或后端服务

Load it locally.本地加载使用。

Until the Chrome Web Store listing is available, clone the repository and load the src/ directory as an unpacked extension.Chrome Web Store 上架前，可以克隆仓库，并将 src/ 目录作为未打包扩展加载。

  1. Open chrome://extensions/.打开 chrome://extensions/。
  2. Enable Developer mode.开启“开发者模式”。
  3. Choose Load unpacked and select src/.点击“加载已解压的扩展程序”，选择 src/。
