Privacy Policy隐私政策

Last updated: October 12, 2026最后更新：2026 年 10 月 12 日

Paste and Go at Right has one purpose: open a URL from the clipboard through Chrome's tab context menu. Paste and Go at Right 的单一用途，是让用户从 Chrome 标签页右键菜单打开剪贴板中的网址。

Data handled处理的数据

The Extension reads plain-text clipboard content locally on the user's device to determine whether it is a complete HTTP or HTTPS URL. When the user selects a menu action, the Extension reads and validates the clipboard again and asks Chrome to open that URL.本扩展会在用户设备本地读取纯文本剪贴板内容，用于判断其是否为完整的 HTTP/HTTPS URL。用户点击菜单时，本扩展会再次读取并校验该内容，然后要求 Chrome 打开该网址。

Clipboard content may contain user data. The Extension processes the current plain-text value only as needed to provide this visible feature.剪贴板可能包含用户数据。本扩展仅为上述用户可见功能临时处理当前纯文本内容。

Storage, transmission, and sharing数据存储、传输和共享

  • Clipboard content is not saved to local storage, files, logs, or databases.
  • Clipboard content and usage data are not sent to the developer, advertisers, analytics services, or any third party.
  • The Extension has no account system, telemetry, analytics, advertising, or remotely hosted code.
  • User data is not sold, and humans are not allowed to read it.
  • 剪贴板内容不会保存到本地存储、文件、日志或数据库。
  • 剪贴板内容和使用数据不会发送给开发者、广告商、分析服务或任何第三方。
  • 本扩展不包含账号系统、遥测、分析、广告或远程代码。
  • 本扩展不会出售用户数据，也不会允许人工读取用户数据。

When a user chooses to open a URL, Chrome visits it as normal browser navigation. The destination website's privacy policy governs its own data practices.当用户选择打开网址时，Chrome 会像正常浏览行为一样访问该网址；目标网站的数据处理受其自身隐私政策约束。

Permission use权限用途

  • clipboardRead — reads the local plain-text clipboard to decide whether to display the menu and obtain the selected URL.在本机读取纯文本剪贴板，以判断是否显示菜单，并在点击时获得要打开的网址。
  • contextMenus — provides actions in Chrome's tab context menu.在 Chrome 标签页右键菜单中提供打开操作。
  • offscreen — provides local clipboard access because a Manifest V3 Service Worker has no DOM.Manifest V3 Service Worker 没有 DOM，因此通过本地隐藏文档访问剪贴板。

Retention and deletion数据保留和删除

The Extension does not persist user data, so there is no server-side or local user-data store to delete. Uninstalling the Extension removes its code and settings.本扩展不持久保存用户数据，因此没有服务器端或本地用户数据需要删除。卸载扩展会移除扩展自身的代码与设置。

Chrome Web Store Limited Use

The Extension's use of user data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only for the clearly disclosed single purpose and is not used for advertising, profiling, credit assessment, resale, or unrelated purposes.本扩展对用户数据的使用符合 Chrome Web Store User Data Policy（包括 Limited Use 要求）：数据仅用于清楚披露的单一功能，不用于广告、画像、信用评估、转售或其他无关用途。

Policy changes政策变更

If data practices change, this policy and the Chrome Web Store disclosures will be updated before the changed version is released.如果数据处理方式发生变化，本政策和 Chrome Web Store 披露会在新版本发布前同步更新。

Contact联系方式

For privacy or support questions, contact the maintainers through GitHub Issues. Do not post clipboard content or other sensitive information in a public issue.如有隐私或支持问题，请通过 GitHub Issues 联系项目维护者。请勿在公开 Issue 中提交剪贴板内容或其他敏感信息。
