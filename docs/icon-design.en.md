# Icon design

[简体中文](icon-design.md) · English

The final original mark combines a clipboard with a northeast open-link arrow. The blue clipboard is the primary form, while the teal-green arrow represents opening a URL.

## Files

- `assets/icon-source.png`: high-resolution design source, excluded from the extension package.
- `../src/icons/`: transparent 16, 32, 48, and 128-pixel PNG files used by Chrome.
- `references/`: Icons8 assets supplied by the user as design references. They are excluded from the extension package and are not the final extension icon.

The rights and licenses for the Icons8 reference assets remain with their respective authors or rightsholders. The release package contains only the project's original generated icon.
